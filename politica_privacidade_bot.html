1. 📌 Sobre o Bot

O Manhattan (“Bot”, “nós” ou “nosso”) é uma aplicação desenvolvida para a plataforma Discord, destinada a fornecer funcionalidades de gerenciamento, moderação, automação e/ou outros recursos para servidores.

O Bot não pertence, não é operado e não é oficialmente associado ao Discord Inc.

2. 📊 Dados que podem ser coletados

Dependendo das funcionalidades utilizadas, o Bot poderá processar:

  • ID do usuário do Discord;
  • Nome de usuário e apelido;
  • ID do servidor;
  • ID dos canais e cargos;
  • Informações necessárias para executar comandos;
  • Data e horário de determinadas interações;
  • Registros de comandos utilizados;
  • Informações relacionadas à moderação;
  • Informações fornecidas voluntariamente por meio de comandos, formulários ou sistemas do Bot.

3. 🚫 Dados que não coletamos intencionalmente

  • Senhas do Discord;
  • Tokens de autenticação;
  • Dados bancários;
  • Informações de cartão de crédito;
  • Documentos pessoais;
  • Endereço residencial;
  • Dados de localização precisa.
Importante: nunca forneça sua senha ou token do Discord ao Bot.

4. 🎯 Como utilizamos os dados

Os dados poderão ser utilizados para:

  • Executar comandos solicitados;
  • Administrar servidores;
  • Aplicar sistemas de moderação;
  • Identificar usuários nos sistemas do Bot;
  • Gerenciar cargos e permissões;
  • Registrar ações administrativas;
  • Prevenir abusos e detectar utilização indevida;
  • Manter a segurança e estabilidade do Bot;
  • Melhorar as funcionalidades do Bot.

5. 💬 Mensagens e conteúdo

Caso alguma funcionalidade do Bot exija acesso ao conteúdo de mensagens, esse acesso será utilizado somente para executar a funcionalidade correspondente.

Quando possível, o Bot deverá processar apenas as informações necessárias para realizar determinada ação.

6. 🗄️ Armazenamento

Quando necessário, determinadas informações poderão ser armazenadas em banco de dados ou sistemas utilizados para o funcionamento do Bot.

Os dados serão armazenados somente pelo período necessário para cumprir a finalidade para a qual foram coletados, salvo quando a manutenção for necessária por obrigação legal, segurança ou resolução de disputas.

7. 🗑️ Exclusão de dados

O usuário poderá solicitar a exclusão dos dados pessoais armazenados pelo Bot.

Para solicitar a exclusão, entre em contato pelo e-mail indicado na seção de contato, informando seu ID do Discord e quais informações deseja excluir.

8. 🔐 Segurança

Adotamos medidas técnicas e administrativas razoáveis para proteger os dados contra acesso não autorizado, divulgação indevida, alteração, perda, destruição e uso indevido.

Entretanto, nenhum sistema conectado à internet pode garantir segurança absoluta.

9. 👥 Compartilhamento de dados

Não vendemos dados pessoais dos usuários.

Os dados poderão ser compartilhados somente quando necessário para funcionamento do Bot, prestação de serviços relacionados, segurança, cumprimento de obrigação legal ou proteção de direitos.

10. 🔗 Serviços de terceiros

O Bot poderá utilizar serviços externos, como hospedagem, banco de dados, APIs ou outros provedores necessários ao seu funcionamento.

Esses serviços poderão possuir suas próprias políticas de privacidade e termos de uso.

11. 🇧🇷 LGPD

Para usuários localizados no Brasil, o tratamento de dados poderá estar sujeito à Lei Geral de Proteção de Dados Pessoais (LGPD — Lei nº 13.709/2018).

Dependendo da situação, os usuários poderão possuir direitos relacionados aos seus dados pessoais, incluindo solicitações de acesso, correção, eliminação e outras medidas previstas na legislação aplicável.

12. 👤 Direitos do usuário

Dentro dos limites da legislação aplicável, o usuário poderá solicitar:

  • Acesso aos dados;
  • Correção de dados incorretos;
  • Exclusão de dados;
  • Informações sobre o tratamento;
  • Revogação de consentimento quando aplicável;
  • Portabilidade quando aplicável;
  • Informações sobre compartilhamento de dados.

13. 👶 Menores de idade

O Bot não deve ser utilizado para coletar deliberadamente informações pessoais de crianças em desacordo com a legislação aplicável.

Os usuários também devem observar os requisitos mínimos de idade estabelecidos pelo Discord.

14. 🔄 Alterações nesta política

Esta Política de Privacidade poderá ser atualizada periodicamente. Quando houver alterações relevantes, a nova versão poderá ser publicada nesta mesma página.

A data da última atualização será indicada no início do documento.
